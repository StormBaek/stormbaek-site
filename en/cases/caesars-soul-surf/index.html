About the project

Same identity. A better experience.

Caesar’s Soul Surf offers surfing experiences in Peru. The brief was to improve the existing website while respecting Richard’s identity and wishes. We kept the overall look and made reviews, experiences, causes and contact easier to find.

What we did

  • 01Google reviews with profile photos and links to the source
  • 02Three selected Instagram videos, a map with directions and a coastal photo
  • 03The Activism page expanded, refined and highlighted in the navigation
  • 04A persistent WhatsApp button with messages tailored to the page and selected package
  • 05Responsive layouts, basic SEO and a completed security scan
